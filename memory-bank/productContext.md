# Product Context

## Problem Statement
Users need a lightweight, no-fuss way to discover TV shows, view essential details, and keep track of their favorites without the bloat of complex social networks or heavy tracking platforms.

## User Goals
- **Search**: Quickly find TV shows by name using the Episodate API.
- **View Details**: Access comprehensive information about a show (status, network, description, start date).
- **Manage Favorites**: Easily add or remove shows from a personal "Favorites" list.
- **Access**: Favorites are stored locally and repopulated on reload.

## Experience Goals
- **Minimalist**: Clean UI with no unnecessary distractions (using `mini.css`).
- **Responsive**: Works well on desktop and mobile devices.
- **Fast**: Immediate feedback on search and interactions.
