# Tech Stack

## Overview
A modern frontend application built with Angular 18 and TypeScript, designed to be hosted as a public static site on GitHub Pages.

## Languages
TypeScript

Leveraging TypeScript for robust type safety, better developer ergonomics, and seamless integration with the Angular ecosystem.

## Framework
Angular 18

Using the latest version of Angular to take advantage of Signals, standalone components, and modern control flow (@if, @for).

## Authentication
None needed

Publicly accessible application without user authentication requirements.

## Infrastructure & Deployment
GitHub Pages

A cost-effective and simple hosting solution for static Angular builds, ideal for public documentation or small tools.

## Package Manager
npm

Standard package management as configured in the existing project workspace.

## Decision Relationships
The choice of GitHub Pages as infrastructure aligns with the "None needed" authentication choice, as static hosting is best suited for public content.
